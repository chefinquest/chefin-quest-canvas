# Chefin Quest Gallery

A minimalist, Web UI Benchmark-inspired gallery for [chefin.quest](https://chefin.quest/).

The site uses the same core page tones as the reference:

- Background: `#fff`
- Thin grid line: `#0000001f`
- Foreground: `#111`
- Muted text: `#666`

Each piece occupies its own full-height page and is centered over a fixed grid that spans the entire viewport.

## Run locally

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm test
npm run lint
npm run build
```

## Stack

- React + TypeScript + Vite
- CSS-only gallery artwork plus the Chefin portal asset
- Vitest
